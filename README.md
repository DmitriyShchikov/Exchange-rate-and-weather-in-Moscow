# Московское табло

Мини-дашборд «Курс валют и погода в Москве»: карточки USD, EUR, температуры,
осадков и времени последнего обновления, плюс кнопка «Обновить».

## Данные

| Карточка | Источник | Запрос |
| --- | --- | --- |
| USD, EUR | Банк России через `cbr-xml-daily.ru` | `https://www.cbr-xml-daily.ru/daily_json.js` |
| Температура, осадки | Open-Meteo | `api.open-meteo.com/v1/forecast`, точка 55.7558° N, 37.6176° E, `timezone=Europe/Moscow` |

Курс показан в формате ЦБ РФ — с точностью до четырёх знаков и с учётом номинала;
рядом изменение к предыдущей дате торгов. В карточке осадков — миллиметры в час
сейчас и полоса вероятности осадков на ближайшие 12 часов.

## Обработка ошибок

Оба запроса идут параллельно (`Promise.allSettled`) с тайм-аутом 12 секунд, поэтому
сбой одного источника не мешает второму. Если источник не ответил, его карточки
показывают, что именно произошло (код ответа, тайм-аут или заблокированный запрос),
ссылку на сам API для проверки и подсказку нажать «Обновить»; сверху появляется
общая плашка со списком недоступных источников.

## Запуск

Отдельный файл без сборки и зависимостей — достаточно открыть `index.html` в браузере
или отдать его любым статическим сервером:

```
python3 -m http.server 8000
```

Оба API отдают CORS-заголовки, так что запросы идут из браузера напрямую. Если страница
открыта в песочнице, которая запрещает сетевые запросы (например, предпросмотр внутри
другого приложения), карточки покажут сообщение о заблокированном запросе — это ожидаемое
поведение, а не ошибка разметки.
